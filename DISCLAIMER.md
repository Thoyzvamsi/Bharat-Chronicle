# Disclaimer

This project uses an AI language model to write historical content about
communities. Please read this before trusting anything it produces.

- This is a learning project and an experiment. It is not a verified
  historical record.
- AI models can be confidently wrong — including mixing up similar names,
  places, or communities with each other.
- Every report is a first draft to be checked by a real person, not a
  finished, authoritative source.
- This project is not written to rank, favor, or promote any community over
  another, and nothing it produces is meant to hurt anyone's feelings. If a
  report reads that way, that's a mistake in the AI's output, not the intent
  of this project — please open an issue so it can be fixed.
